Impedance measurements and structural health monitoring

Data-driven parametric reduced order modeling of impedance measurements

ResultA reduced model with a norm error of 1e-4 relative to reference data.

A reduced order model captures the essential behavior of a measured response with far fewer parameters than the raw data. This project builds data-driven parametric reduced order models of impedance measurements.

What I did

  • Developed a parametric reduced model using a Lagrangian basis function.
  • Implemented frequency-based data analysis routines that support calibration and traceability for vibration monitoring systems.

Tools and methods

  • Vector fitting
  • Parametric reduced order modeling
