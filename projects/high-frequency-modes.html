Impedance measurements and structural health monitoring

High-frequency modes in electromechanical impedance measurement using non-contact vibration testing

ResultA classification strategy for modes from 0 to 100 kHz.

This project uses non-contact vibration testing to understand the high-frequency modes that appear in electromechanical impedance measurements.

What I did

  • Designed and ran multi-sensor, non-contact modal tests with a 3D scanning laser Doppler vibrometer and an impedance analyzer with piezoceramic excitation.
  • Proposed classification strategies for high-frequency modes using clustering and signal processing, which improve accuracy and clarity.

Tools and methods

  • Polytec 3D scanning LDV
  • Impedance analyzer
  • Clustering and signal processing

Publication

Sangle, Rogers, Albakri & Tarazaga (2024), IMAC 2024. Understanding High-Frequency Modes in Electromechanical Impedance Measurement Using Non-contact Vibration Testing.
